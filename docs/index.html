Check a laptop before the return window closes.

One PowerShell command reads the hardware, firmware and event logs. It tells you if this is the machine you paid for, whether anyone tampered with it, and how much it was really used. Then it writes a PDF you can send the seller.

Run it. Windows 10 or 11, admin PowerShell
Set-ExecutionPolicy -Scope Process Bypass -Force
Invoke-WebRequest https://github.com/blackdragoon26/stressTestIt_beforeReturnWindowCloses/archive/refs/heads/main.zip -OutFile $env:TEMP\omen-kit.zip -UseBasicParsing
Expand-Archive $env:TEMP\omen-kit.zip -DestinationPath C:\omen-kit -Force
cd C:\omen-kit\stressTestIt_beforeReturnWindowCloses-main
.\omen-audit.ps1

Read-only. Nothing installed. Nothing uploaded. Open source. Check the download first.

What it checks

Identity

Serial against your invoice, product number, model, board ID.

Genuine parts

CPU core count, GPU and its memory, RAM, SSD size, the panel's resolution and refresh, battery capacity.

Prior use

SSD power-on hours and terabytes written, read straight from the drive. Battery wear and cycles.

Tampering

Secure Boot and its keys, BIOS passwords, company or MDM enrollment, boot entries, leftover software.

Stability

Hardware errors, crashes, unexpected shutdowns, GPU driver resets, devices that vanished.

Under load

A sensor log during stress tests: GPU dropouts, thermal and power brakes, sustained watts.

Every check and its rules

A real result

From the laptop this kit was tested on. Windows' own counters showed nothing for the SSD. The kit read the drive directly:

FAILUnexpected shutdowns: 4 in 30 days. Latest 2026-11-11, 11-10, 11-07, 10-25
WARNSSD health: power-on 19,278 h, written 72.21 TB, wear 100%, 207 unsafe shutdowns
WARNBattery: 61% of design capacity, 1,833 cycles
PASSCPU, GPU, display, RAM, Secure Boot keys, no company enrollment

The same numbers smartctl reads on Linux, matched to the hour.

What you get

  • A PDF report. Every result, every part with its exact model and serial, sensor charts, and the raw outputs.
  • Fingerprints. A SHA-256 manifest proves no file was edited after the run.
  • Three modes. A full audit on day one, a sensor log for every stress test, and a quick check every evening.

Supported laptops

Any Windows laptop runs in generic mode: every health, tamper and prior-use check, with specs listed. With a profile, every spec is also compared against what the maker promised.
