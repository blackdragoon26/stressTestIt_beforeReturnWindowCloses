Check your laptop before the return window closes.

One command reads the hardware, firmware and logs. It tells you if this is the machine you paid for, whether anyone tampered with it, and how much it was really used. You get a report to keep as proof.

Terminal (Admin): press Win + X
Set-ExecutionPolicy -Scope Process Bypass -Force
Invoke-WebRequest https://github.com/blackdragoon26/stressTestIt_beforeReturnWindowCloses/archive/refs/heads/main.zip -OutFile $env:TEMP\omen-kit.zip -UseBasicParsing
Expand-Archive $env:TEMP\omen-kit.zip -DestinationPath C:\omen-kit -Force
cd C:\omen-kit\stressTestIt_beforeReturnWindowCloses-main
.\omen-audit.ps1

Writes a PDF report. Add -Monitor -Minutes 60 during stress tests and -Quick every evening.

Terminal, on the installed system or a live USB
(curl -fsSL https://github.com/blackdragoon26/stressTestIt_beforeReturnWindowCloses/archive/refs/heads/main.tar.gz || wget -qO- https://github.com/blackdragoon26/stressTestIt_beforeReturnWindowCloses/archive/refs/heads/main.tar.gz) | tar -xz -C ~
cd ~/stressTestIt_beforeReturnWindowCloses-main
sudo bash linux-live-audit.sh --install

Writes an HTML report. Add --stress for a 15 minute verified CPU and memory test. From a live USB it checks a Windows laptop from outside Windows.

Terminal
curl -fsSL https://github.com/blackdragoon26/stressTestIt_beforeReturnWindowCloses/archive/refs/heads/main.tar.gz | tar -xz -C ~
cd ~/stressTestIt_beforeReturnWindowCloses-main
bash mac-audit.sh

Experimental: not yet run on a real Mac. Writes an HTML report. For SSD hours, install smartmontools first.

Read-only. Nothing installed unless you ask. Nothing uploaded. Open source. Check the download first.

What it checks

Identity

Serial against your invoice, model, product number, board ID.

Genuine parts

CPU core count, GPU and its memory, RAM, SSD size, the panel's resolution, battery capacity.

Prior use

SSD power-on hours and terabytes written, read from the drive itself. Battery wear and cycles.

Tampering

Secure Boot and its keys, firmware passwords, company enrollment, Activation Lock on Macs.

Stability

Hardware errors, crashes, kernel panics, unexpected shutdowns, devices that vanished.

Under load

Sensor logs and verified stress tests: GPU dropouts, thermal brakes, memory errors.
